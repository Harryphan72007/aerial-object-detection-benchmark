# Reproducibility checklist

Before publishing a result:

- [ ] dataset source URL, download date, and checksum recorded
- [ ] dataset terms reviewed; no source imagery redistributed
- [ ] immutable train/validation/test split recorded
- [ ] exact config and Git commit recorded
- [ ] package lock or environment export attached
- [ ] model code and checkpoint licenses verified separately
- [ ] pretrained checkpoint identifier and hash recorded
- [ ] random seed and deterministic settings recorded
- [ ] failed, pruned, and out-of-memory trials retained
- [ ] equal search budget enforced across families
- [ ] final configuration selected without test-set feedback
- [ ] three final seeds completed
- [ ] hardware, driver, framework, precision, and batch size recorded
- [ ] latency warm-up and synchronization documented
- [ ] prediction artifact hash recorded
- [ ] aggregate and per-class metrics generated by shared evaluation code
- [ ] confidence intervals or seed dispersion reported
- [ ] qualitative errors sampled without cherry-picking
- [ ] `TBD` values replaced only from committed artifacts
